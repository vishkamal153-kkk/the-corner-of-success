# The Corner of Success

A student career-exploration app by Vishwa, Ritwik, and Ishaan. Explore ten career paths, direct article links, learning resources, and hands-on challenges. The public Credits & Resources page lists the sources and privacy details.

## Run

Open `index.html` in a browser. No build, dependencies, or application server is required. The HTML includes the styles and JavaScript. Google Fonts needs an internet connection; system fonts provide a fallback.

## Demo profiles and privacy

**This is a learning demo, not secure authentication.** Use a nickname, a made-up email like `explorer@example.test`, and a password never used elsewhere. Local storage contains demo names, email addresses, salts, password digests, and exercise progress. Session storage tracks the selected profile. Anyone with access to the browser can inspect or change this data and bypass the demo login. Password hashing does not turn it into secure authentication.

There is no account server or cross-device synchronization. The app does not upload profile fields or progress. Clear this site's browser data to erase profiles, progress, and preferences. Previously created profiles do not automatically transfer to the published site.

Hosting and font providers receive ordinary web requests; linked services receive requests when a visitor follows a link. Their own privacy policies apply. Public repository files are visible to everyone: never commit credentials, browser exports, real account records, or other private data.

## Publish with GitHub Desktop and GitHub Pages

1. Add this folder as a local repository in GitHub Desktop (create a repository here if prompted).
2. Commit the project files to `main`.
3. Choose **Publish repository**, name it `the-corner-of-success`, and uncheck **Keep this code private** for a public repository. Publish.
4. On GitHub, open the repository's **Settings → Pages**.
5. Select **Deploy from a branch**, then **main** and **/(root)**, and click **Save**.
6. Wait for the Pages deployment to succeed, then open **Visit site**. Check the app, articles, and credits before sharing the URL.

GitHub serves the static files over HTTPS. There is no Node.js, Python, database, or authentication server running for this app.

Official setup instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
